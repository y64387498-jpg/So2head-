# S2 HEAD CONTROL

Mobil uyumlu, HTML/CSS/JavaScript tabanlı karakter önizleme arayüzü.

## Dosyalar
- `index.html` — sayfa yapısı
- `style.css` — görünüm ve mobil düzen
- `script.js` — slider ve Android uygulama açma denemesi

## Kullanım
1. Depoyu GitHub'a yükleyin.
2. `index.html` dosyasını tarayıcıda açın.
3. Kafa boyutu slider'ı yalnızca demo karakterini değiştirir.

## Android notu
START düğmesi `com.axlebolt.standoff2` paketini Android intent bağlantısıyla açmayı dener. Bunun çalışması, uygulamanın WebView kapsayıcısının dış uygulama intent'lerini desteklemesine bağlıdır.

Bu proje Standoff 2 oyun dosyalarını, gerçek karakter görünümünü veya hitbox'ları değiştirmez.
